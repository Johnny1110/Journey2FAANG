# 備審資料（30%）＋ 口試（40%）

> 這兩項合計 70%，比筆試更重。備審可以提前做完鎖定分數；口試在筆試放榜後只有約一週準備時間，所以題庫要在 Phase 4 就先寫好。

<br>

## 備審資料 Checklist（30%）

繳交項目（依 115 學年度規定）：

- [ ] 學位證書影本
- [ ] 大學歷年成績單
- [ ] 服務年資證明書（確認合計 3 年以上＋同一機構連續 1 年以上，算至報名截止日）
- [ ] 個人資料表（報名系統上傳，115 學年度時程：報名後幾天內截止，不要拖）
- [ ] **工作成果／有利審查資料** ← 決勝項
- [ ] **推薦函 2 封（至多 3 封）** ← 決勝項

### 工作成果集怎麼做

* 挑 2～3 個最有技術含量的專案：架構圖＋你的角色＋量化成果（QPS、成本、時程）
* 你的 [interview_in_action](../../interview_in_action) 與 [behavioral_training](../../behavioral_training/README.md) 素材直接改寫成中文書面版
* 把「為什麼要讀碩士」的敘事線埋進去：工作遇到的技術瓶頸 → 需要系統性學術訓練 → 為何是台大資工
* GitHub（包括這個 FAANG 訓練 repo 本身！）可以放進去，展示持續學習的紀律

### 推薦函時程

- [ ] **2026/12 底前**發出邀請：首選直屬主管＋一位資深技術同事或大學教授
- [ ] 提供推薦人「懶人包」：你的履歷、想強調的 2～3 個亮點、報名時程
- [ ] 2027/01 底前收齊初稿，留 buffer

<br>

## 口試準備（40%）

口試資格：筆試＋審查前 12 名（約 12 取 8）。形式通常是 10～15 分鐘：自我介紹＋教授提問。

### 必備題庫（每題寫逐字稿 → 濃縮成條列 → 練到脫稿）

**動機類（必考）**

- [ ] 2 分鐘自我介紹（工作經歷為主軸，收尾在「為什麼現在要讀碩士」）
- [ ] 為什麼讀碩士？為什麼在職專班而不是一般碩士班？
- [ ] 為什麼是台大資工？（做功課：看系上教授的研究領域，講出 1～2 個有興趣的 lab／方向）
- [ ] 工作這麼忙，如何兼顧學業？（要有具體的時間規劃答案，教授真的很在意修不修得完）
- [ ] 畢業後的規劃？碩士學位對你的職涯幫助是什麼？

**技術類**

- [ ] 介紹一個你最有代表性的專案（架構、你的貢獻、trade-off）——從 behavioral 素材改中文版
- [ ] 你的工作中遇過最難的技術問題？怎麼解的？
- [ ] 想跟哪位教授做什麼方向的研究？為什麼？（至少準備一個具體方向＋讀過該領域 1～2 篇入門材料）

**追問防守**

- [ ] 筆試哪科考差了 → 誠實＋展示你後續怎麼補（不要辯解）
- [ ] 大學成績不理想（如果適用）→ 用工作成果證明現在的你

### 演練方式

* 對 Claude 說 `ntu: 口試模擬`，我扮演口試委員連續追問，之後給回饋
* 手機錄影自己講一次，檢查贅字與眼神
