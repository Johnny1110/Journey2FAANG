# 考古題訓練與錯題本

> Phase 3（2026/12 中 ～ 2027/01）主戰場。考古題是唯一能告訴你「台大怎麼出題」的資料，比任何猜題都準。

<br>

## 考古題來源

1. **[台大圖書館考古題系統](https://exam.lib.ntu.edu.tw/)** — 首選。搜尋方式：
   * 系所選「資訊工程學系」，找**碩士在職專班**的「計算機概論」「資料結構」（在職專班歷史較短，份數可能有限）
   * 再抓**資工所一般碩士班**的考題當進階練習（難度較高，把基本題挑出來寫即可，難題看得懂解法就好）
2. **[PTT NTU-Exam 精華區](https://www.ptt.cc/man/NTU-Exam/DE0A/D245/D298/DE44/index.html)** — 部分題目有鄉民解答
3. **[HackMD 資工所考古題詳解整理](https://hackmd.io/@afuoVpqBTE60TjqvxK7JHA/cs_graduate)** — 近年各校資工所詳解、筆記
4. 下載的 PDF 統一放本資料夾，命名：`{年度}_{科目}.pdf`（例：`114_資料結構.pdf`）

<br>

## 練習規則

1. **限時 80 分鐘、手寫、不翻書**——從第一份就全真模擬，不要「先看一下題目」
2. 寫完先自評，再用 `score: ntu past_exams/{年度}_{科目}` 請 Claude 批改
3. 每份考卷產出 2～3 條「錯題卡」寫進下方錯題本
4. 錯題本每兩週回顧一次，連錯兩次的主題回到章節清單重讀
