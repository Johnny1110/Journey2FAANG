# Vocabulary 詞彙表

<br>

---

<br>

所有練習（閱讀、聽力、寫作批改、口說回饋）遇到的生字與片語都收進 [vocab.md](vocab.md)。這是長期資產：TOEFL 之後接著用在 OMSCS 課程與面試英文。

<br>

## 使用方式

| 動作 | 怎麼做 |
| --- | --- |
| 加生字 | 自己編輯 `vocab.md`，或說 `toefl: vocab add <word/phrase>`，Claude 會自動補音標、詞性、中文、例句 |
| 複習測驗 | 說 `toefl: vocab quiz`，Claude 依詞彙表出題（中翻英、克漏字、選詞填空、造句），測驗存到 `quiz/` |
| 標記熟練度 | quiz 答錯的字，Claude 會把該字的 ★ 升級（★ 越多 = 越常錯，出題優先） |

## 測驗規則

* 每次 quiz 以 **最近 2 週新增** + **★ 標記字** 為主，混少量舊字防遺忘
* 連續兩次 quiz 都答對的 ★ 字，降一級
* 題型輪替，不要每次都考中翻英

<br>

## 檔案

* [vocab.md](vocab.md) — 詞彙表本體
* `quiz/` — 歷次複習測驗與結果
