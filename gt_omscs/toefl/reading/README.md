# TOEFL Reading

<br>

---

<br>

每週一回，由 Claude 依 2026 新制題型出題。流程：

1. 我說 `toefl: init reading` → Claude 建立 `weekXX/README.md`（題目）
2. 我把作答寫在 `weekXX/answer.md`
3. 我說 `toefl: score reading weekXX` → Claude 產出 `weekXX/feedback.md`（分數 + 逐題解析 + 生字建議加入詞彙表）

<br>

## 新制題型（每回練習應涵蓋）

| 題型 | 說明 | 練習重點 |
| --- | --- | --- |
| Complete the Words | 學術段落中每段 10 個單字缺後半字母，補完 | 詞彙量 + 構詞（字首字尾） |
| Read in Daily Life | email、公告等生活短文（15–150 字），2–3 題選擇 | 快速抓目的與細節 |
| Read an Academic Passage | ~200 字學術短文，5 題選擇 | 主旨、推論、指代、詞義 |

計時要求：整回控制在 **27 分鐘**內完成，模擬真實節奏。
