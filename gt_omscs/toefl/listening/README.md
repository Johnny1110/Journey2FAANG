# TOEFL Listening

<br>

---

<br>

每天 20–30 分鐘：**精聽**（跟著資源做聽寫/跟讀）+ **泛聽**（podcast 當背景習慣）。新制題型是 Choose a Response / Conversation / Announcement / Academic Talk，全部偏短、節奏快，重點是第一次就聽懂，不靠回放。

## 精聽 SOP（每次 20–30 min）

1. 挑一段 1–3 分鐘音檔，**不看稿**聽一次，寫下大意
2. 逐句聽寫，卡住的句子最多重播 3 次
3. 對照逐字稿，把沒聽出來的字/連音標記出來 → 生字加入 [詞彙表](../vocabulary/README.md)
4. 跟讀（shadowing）整段 2 次，模仿語調和連音
