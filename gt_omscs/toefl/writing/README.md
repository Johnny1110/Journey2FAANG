每週一回，由 Claude 依 2026 新制題型出題。流程：

1. 我說 `toefl: init writing` → Claude 建立 `weekXX/README.md`（題目，含每題計時上限）
2. 我**計時**作答，寫在 `weekXX/answer.md`
3. 我說 `toefl: score writing weekXX` → Claude 產出 `weekXX/feedback.md`（band 1–6 評分 + 逐句修改 + 更好的句型/用字示範）

<br>

## 新制題型（每回練習應涵蓋）

| 題型 | 限時 | 說明 |
| --- | --- | --- |
| Build a Sentence | 短 | 依提示從候選字組出正確句子（文法排序） |
| Write an Email | 7 min | 依情境寫一封短 email（如：向教授請假、詢問課程） |
| Writing for an Academic Discussion | 10 min | 課堂討論版發文：表態 + 論證 + 回應他人觀點 |

評分維度：任務完成度、組織、文法正確性、用字多樣性。
